# 赤とんぼCC スコア評価

**赤とんぼカントリークラブ**（旧 神崎カントリー倶楽部／千葉県香取郡神崎町）のスコアを入れると、
**100点満点の評価・評価ランク S〜E・推定ハンディキャップ・ホール別の内訳**を出すウェブアプリです。
ビルド不要・依存ゼロ・データは端末内にのみ保存されます。

## できること

| | |
|---|---|
| **採点** | パー72との差から0〜100点と評価ランク（70台=S／80台=A／90台=B／100台=C／110台=D／120以上=E） |
| **推定ハンディキャップ** | スコアディファレンシャル `(113 ÷ スロープ) × (スコア − コースレート)`。3ラウンド以上たまるとWHSの少数ラウンド表で指数を算出 |
| **推定順位** | アマチュアのスコア分布から「上位N%」 |
| **18ホール入力** | ホールごとの打数を入れると、バーディ／パー／ボギー／ダボ／トリプル以上の内訳、OUT・IN別、パー3/4/5別の平均、いちばん叩いたホールまで |
| **パット・パーオン** | 1ホール平均パット、ショット数（スコア−パット）、パーオン率 |
| **次の目標** | 1ランク上に届く打数と「あと何打」 |
| **履歴** | ラウンドごとに保存して評価スコアの推移を折れ線で表示（この端末のブラウザ内のみ） |

## コースデータ

`src/course.js` に集約しています。

**公開情報にもとづく確定値**

| 項目 | 値 |
|---|---|
| ホール数 / パー | 18ホール / パー72（OUT 36・IN 36） |
| 距離 | バックティ 6,539ヤード |
| グリーン | ベント1グリーン |
| 設計 | 三浦一美 |
| 開場 | 1994年（2022年に神崎カントリー倶楽部から改称・リニューアル） |
| コース種別 | 丘陵・林間 |
| 所在 | 千葉県香取郡神崎町 |

**暫定値（スコアカードの数字に差し替えてください）**

- `TEES[].courseRating` / `TEES[].slope` — 公式レートを確認できなかったため、
  6,539ヤード・パー72の丘陵コースとして一般的な値を置いています。
  ここを直すと**推定ハンディキャップが正確になります**。
- `TEES[].yards`（レギュラー・フロント） — バックティ以外の距離は推定です。
- `HOLES[].par` — 合計72は確定ですが、ホールごとの配分は確認できませんでした。
  一般的なパー72の並びを置いています。ここを直すと**ホール別の内訳が正確になります**。

```js
// src/course.js
{ id: 'back', label: 'バック', yards: 6539, courseRating: 71.0, slope: 126, estimated: true },
//                                          ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^ スコアカードの値に
```

`HOLES[].note` にはコースガイドで繰り返し挙げられる特徴（2番の左ドッグレッグ、4番の右ドッグレッグ、
11・16・18番の池）を入れてあります。いちばん叩いたホールのコメントに出ます。

## 動かす

```bash
git clone https://github.com/croppenne/manga3.git
cd manga3
npm start          # http://localhost:8000 を開く（python3 -m http.server）
```

ES モジュールを使っているため `index.html` を `file://` で直接開くと動きません。
ローカルサーバー経由で開くか、1枚にまとめたビルドを使ってください。

```bash
npm run build:artifact   # dist/artifact.html（単体で開ける1ファイル版）
```

## テスト

評価ロジックは DOM に依存しない純粋関数だけで書いてあるので、そのまま検証できます。

```bash
npm test           # node --test（外部依存なし）
```

パー合計が72であること、評価ランクの境界が70台・80台…と一致すること、
スコアディファレンシャルがWHSの式どおりであること、少数ラウンド表が規定どおりであることなどを確認しています。

## 評価の仕組み

1. **採点** — `パー72との差` を折れ線で0〜100点に写します。区切りはアマチュアの実感（70台・80台…）と
   一致させてあるので、点数の帯とランクがずれません。
2. **ハンディキャップ** — 1ラウンドごとにスコアディファレンシャルを出し、履歴が3ラウンド以上たまると
   ワールドハンディキャップシステムの少数ラウンド表（3ラウンドなら最良1本−2.0、20ラウンドなら最良8本の平均）で指数にします。
3. **推定順位** — アマチュアのスコアが平均100打・標準偏差13打の正規分布に従うという仮定による目安です。

## ファイル構成

```
index.html               画面のマークアップ
assets/styles.css        配色（ライト/ダーク）とレイアウト
src/course.js            コースデータと評価基準 ← 調整するのはここ
src/scoring.js           採点ロジック（純粋関数・テスト対象）
src/history.js           ラウンドの保存（localStorage）
src/app.js               画面の組み立てとイベント
tests/scoring.test.mjs   評価ロジックのテスト
tools/build-artifact.mjs 1ファイル版のビルド
```

## プライバシー

入力したスコアと配色の設定はブラウザの `localStorage` にだけ保存されます。
サーバーへの送信は一切ありません。履歴は「履歴をすべて消す」でいつでも削除できます。
