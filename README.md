# 赤とんぼクロスカントリー 記録評価

完走タイムを入れると、部門ごとの基準タイムと比べて **100点満点 + 評価ランク（S〜E）** で採点するウェブアプリです。
ビルド不要・依存ゼロ・データは端末内にのみ保存されます。

![アプリの構成](https://img.shields.io/badge/deps-0-informational) ![tests](https://img.shields.io/badge/tests-node%3Atest-informational)

## できること

| | |
|---|---|
| **採点** | 部門・距離・完走タイム・コース状況から 0〜100 点と評価ランク S/A/B/C/D/E |
| **推定順位** | 同部門のタイム分布から「上位 N%」を推定。実際の順位を入れると答え合わせもします |
| **目標タイム** | 次のランクに届くタイムと、あと何秒縮めればよいか |
| **距離換算** | 同じ走力なら 1〜10km をどれくらいで走れるか（部門の基準タイム付き） |
| **記録の履歴** | 大会ごとに保存してスコアの推移を折れ線で表示（この端末のブラウザ内のみ） |

## 動かす

```bash
git clone https://github.com/croppenne/manga3.git
cd manga3
npm start          # http://localhost:8000 を開く（python3 -m http.server）
```

ES モジュールを使っているため `index.html` を `file://` で直接開くと動きません。
ローカルサーバー経由で開くか、1 枚にまとめたビルドを使ってください。

```bash
npm run build:artifact   # dist/artifact.html（単体で開ける1ファイル版）
```

## テスト

評価ロジックは DOM に依存しない純粋関数だけで書いてあるので、そのまま検証できます。

```bash
npm test           # node --test（外部依存なし）
```

## 評価の仕組み

1. **基準タイム** — 部門ごとに「平均的な完走者の 3km タイム」(`base3k`) を持ちます。
2. **距離換算** — Riegel 式 `T2 = T1 × (D2/D1)^1.06` で入力距離の基準タイムに直します。
3. **コース補正** — 起伏・路面に応じて基準タイムを ±数％ 動かします（タフなコースほど基準が緩む）。
4. **採点** — `比率 = 実タイム ÷ 基準タイム` を折れ線で 0〜100 点に写します。
   基準タイムちょうどが **60点・評価C**。
5. **推定順位** — 完走タイムが対数正規分布（中央値 = 基準 × 1.06、log の標準偏差 0.15）に
   従うと仮定して「上位 N%」を出します。

| 評価 | 点 | 目安 |
|---|---|---|
| S | 90〜100 | 入賞圏 |
| A | 80〜89 | 上位 |
| B | 70〜79 | 好記録 |
| C | 60〜69 | 標準（＝基準タイム） |
| D | 45〜59 | 完走ペース |
| E | 0〜44 | チャレンジ |

### 基準タイムについて（重要）

同梱の `base3k` は、一般的な市民クロスカントリー大会の完走タイムから置いた **暫定値** です。
赤とんぼクロスカントリーの公式記録ではありません。

過去のリザルトが手元にあれば、`src/criteria.js` の `DIVISIONS[].base3k` を
**その部門の完走タイムの平均（3km 換算・秒）** に差し替えてください。
それだけで全部門・全距離・全機能の評価が実データに沿ったものになります。

```js
// src/criteria.js
{ id: 'a30m', group: '一般', label: '一般 男子（18〜39歳）', base3k: 660 },
//                                                          ^^^ 11:00 → 実データの平均に
```

部門の増減、距離プリセット、コース係数、スコア曲線（`SCORE_ANCHORS`）、
ランクの境界（`GRADES`）も同じファイルにまとまっています。

## ファイル構成

```
index.html              画面のマークアップ
assets/styles.css       配色（ライト/ダーク）とレイアウト
src/criteria.js         評価基準データ ← 調整するのはここ
src/scoring.js          採点ロジック（純粋関数・テスト対象）
src/history.js          記録の保存（localStorage）
src/app.js              画面の組み立てとイベント
tests/scoring.test.mjs  評価ロジックのテスト
tools/build-artifact.mjs 1ファイル版のビルド
```

## プライバシー

入力した記録と配色の設定はブラウザの `localStorage` にだけ保存されます。
サーバーへの送信は一切ありません。履歴は「履歴をすべて消す」でいつでも削除できます。
